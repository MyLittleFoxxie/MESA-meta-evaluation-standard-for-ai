Fictional benchmark: AddTwo measures exact integer addition on a bounded task space of identical small pairs, {(1, 1), (2, 2)} (total n = 2 tasks, exhaustively covering this range with no held-out split).
The two tasks are (1, 1) -> 2 and (2, 2) -> 4, with a manual key checked twice with no errors.
Accuracy is exact match: correct answers divided by two.
Model predictions are evaluated offline in a separate process without access to the answer key.
No human comparison is claimed. No reliability analysis, uncertainty estimate, or exposure check was performed.
All code and data are released into the public domain under CC0 1.0.

SOURCE repository/README.md
AddTwo benchmark.
Task space: integer pairs (a, b) with a = b in {1, 2}. Both n = 2 tasks are included exhaustively, chosen by the author: (1, 1) -> 2 and (2, 2) -> 4.
Run python score.py to print exact-match accuracy for a predictions list in a separate process.
Python 3. No external packages. Code and data are released under CC0 1.0 (see LICENSE).
This benchmark does not test other addition problems.
