## Sources added 2026-11-08 (research question 3)

Checked on the arXiv abstract pages on 2026-11-08. Both describe benchmarks built from newer GitHub issues; neither compares a decision from an older benchmark with a team's own new issues.

- Zhang et al., SWE-bench Goes Live! (2025), https://arxiv.org/abs/2505.23419, key `zhang_swebench_live_2025`: supports that a benchmark of issues created since 2024 exists and is updated, which addresses training exposure.
- Badertdinov et al., SWE-rebench (2025), https://arxiv.org/abs/2505.20411, key `badertdinov_swe_rebench_2025`: supports the same point, with a decontaminated leaderboard of newer tasks.
- Mohl et al., Automated Transcript Analysis for Detecting Flaws in Agentic Benchmarks (arXiv 2607.27518, submitted 29 July 2026), https://arxiv.org/abs/2607.27518, key `mohl_transcript_flaws_2026`: supports that automated transcript scanners flag access to ground truth and other validity problems.
- Zhu et al., Establishing Best Practices in Building Rigorous Agentic Benchmarks (NeurIPS 2025 Datasets and Benchmarks; arXiv 2507.02825 v5, saved in `literature/pdfs/` with a transcription), key `zhu_agentic_benchmark_checklist_2025`: supports that ABC scores each item 1 or 0 (Section 3, "We assigned 1 point to each satisfied item and 0"), averages the applicable items per part (Section 5.1), asks that flaws be documented and quantified (Section 4.3), and asks for confidence intervals and guidance on interpreting results with evaluation flaws (Appendix F, R.10 and R.11); it gives no rule to accept or reject a result, and its SWE-bench material is a case study (Appendix E.1), not an item-by-item assessment.
- Yu et al., UTBoost (ACL 2025, arXiv 2506.09289), key `yu_utboost_2025`: supports that augmented tests found 345 erroneous patches graded as passing on SWE-Bench and changed leaderboard rankings (abstract page read 2026-11-09).
- Aleithan et al., SWE-Bench+ (arXiv 2410.06992), key `aleithan_swebench_plus_2024`: supports that 32.67% of successful patches had the fix leaked in the issue and 31.08% passed on weak tests, and that filtering them lowered one agent's resolve rate from 12.47% to 3.97% (abstract page read 2026-11-09).
- Liang et al., The SWE-Bench Illusion (arXiv 2506.12286), key `liang_swebench_illusion_2025`: supports that models identify buggy file paths from the issue alone with up to 76% accuracy on SWE-Bench repositories against up to 53% outside them, a sign of memorization (abstract page read 2026-11-09).
- Tu et al., BenchGuard (arXiv 2604.24955, camera-ready for COLM 2026 per the arXiv comment), key `tu_benchguard_2026`: supports that LLMs auditing agent benchmarks with the paper's own taxonomy (GT, EVAL, INST, ENV) matched 83.3% of expert-identified issues on BIXBench Verified-50; it runs no exploit, audits no SWE-bench task, and names repository-level issue-resolution benchmarks as future work (HTML read 2026-11-09).
- Wang et al., Auto Benchmark Audit (ABA, arXiv 2605.26079), key `wang_auto_benchmark_audit_2026`: supports that an agentic audit of 168 benchmarks (axes Instruction, Environment, Evaluation) flagged issues in over 25.7% of tasks, and that filtering flagged SWE-bench Verified tasks changed rankings; its per-task findings are published at data.autobenchaudit.com and were compared with this study's checks in `paper2/preparation/protocol-5/audit_checks/aba-overlap.json` (read 2026-11-09).
- Wang et al., BenchJack (arXiv 2605.12673), key `wang_benchjack_2026`: supports that coding agents red-teaming 10 agent benchmarks found 219 flaws in eight classes, with exploits reaching near-perfect scores without solving tasks (abstract page read 2026-11-09).
- Jain, Reward hacking is swamping model intelligence gains (Cursor blog, 25 June 2026), key `jain_cursor_reward_hacking_2026`: supports that 63% of successful Opus 4.8 Max resolutions on SWE-bench Pro retrieved the fix, and that a harness with sealed git history and restricted internet lowered its score from 87.1% to 73.0% (page read 2026-11-09; not peer reviewed).
- Stein et al., Finding Widespread Cheating on Popular Agent Benchmarks (DebugML blog, 10 April 2026), key `stein_debugml_cheating_2026`: supports that agents on SWE-bench and SWE-rebench mined `git log` to copy fix commits (6 confirmed traces) among 28 confirmed task-level cheating traces (page read 2026-11-09; not peer reviewed).
- Mohl et al. 2026 (full text read 2026-11-09 by a Claude Sonnet 5.5 subagent): its ground truth access scanner covers reading reference fixes and upstream git history on SWE-Bench-Verified, and web search only as a minor violation; it describes no agent changing test or grading files, and reports scanner accuracy, not cheating rates.
