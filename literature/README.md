# Literature

This folder holds the source literature for the two REFSQ 2027 papers, [`mesa_paper.tex`](../mesa_paper.tex) and [`paper2.tex`](../paper2.tex). The shared bibliography is [`references.bib`](../references.bib). Most cited sources have no local copy and exist only as bibliography records.

## Contents

- [`slr-2026-10-28/`](slr-2026-10-28/README.md): literature review of benchmark review methods, 28 October 2026. The author review is pending.
- [`slr-extension-2026-11/`](slr-extension-2026-11/README.md): extension of that review for REFSQ, on benchmark quality and evidence reuse in requirements engineering.
- [`pdfs/`](pdfs/) and [`transcriptions/`](transcriptions/): local copies of seven cited sources, listed below. The original PDF remains authoritative where the extracted text loses layout or table detail.
- [`notes/paper2-sources.md`](notes/paper2-sources.md): third-party pages and papers used by Paper 2. The repository is public, so it keeps only their addresses, hashes, and short quotes; the copies stay outside the repository.
