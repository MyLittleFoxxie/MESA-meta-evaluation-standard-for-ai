# R383: Croissant Tasks: A Metadata Format for Reproducible Machine Learning Evaluations

Benjelloun, Omar; Bianco, Leonardo Martins; Guyon, Isabelle; Khuong, Thanh Gia Hieu; Lebensold, Jonathan; Lobentanzer, Sebastian; Oala, Luis; Rachmat, Benedictus Kent; Ullah, Ihsan; Vahidi, Peyman; Vanschoren, Joaquin. First public date recorded: 2026-05-28.

[Primary record](https://arxiv.org/abs/2605.29786) · [Inspected source](<../fulltext/R383.pdf>)

**Source type.** Metadata specification with implementation experiments

**Purpose.** Make evaluation tasks reproducible through machine readable descriptions.

**Intended reviewers.** Benchmark maintainers, researchers and tool/agent developers.

**Concepts and criteria.** Task specifications, datasets, scoring, metadata and reproducibility.

**Answer format and guidance.** Declarative task descriptions extending Croissant; implementations and agent experiments.

**Missing information.** Missing implementation details constrain reproduction. Machine readable metadata does not ensure valid measurement.

**Accessibility and effort.** Reduces some implementation barriers by design; agent performance is not evidence of human review effort reduction.

**Evaluation and findings.** Specification with reproduction examples and automated experiments.

**Evidence assessment.** Coverage of tasks and tools limits generality; adoption and documentation remain requirements.

**Evidence locator.** Sections 3–5, limitations PDF p. 9.
