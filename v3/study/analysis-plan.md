# Analysis plan

Freeze before main responses. Analyze each ten criterion response without repairing it. Validate IDs, count, rating/status consistency and evidence fields. Keep missing, failed, invalid and unstarted jobs visible. Count tool calls by completed event ID, not by start plus completion. A repository session with a failed source call and no successful source call has failed condition delivery and is excluded from the access contrast; a session that chooses not to call tools is reported separately, not silently treated as inspection.

Report rating/status distributions by condition and benchmark, pairwise repeat matches within each benchmark and condition (ten judgments each), and access transitions for each benchmark and repetition. A match requires both status and rating to match. These are repeated observations, not independent samples. Do not use hypothesis tests or mean quality scores.

Check whether cited files exist within that condition's sources. Check exact quotes and whitespace-normalized quotes separately; normalization does not establish semantic support. Treat ellipses, punctuation changes and extraction differences as nonmatches pending inspection, not automatic hallucinations. Check line/page locator format and whether it resolves when a locator can be parsed. Do not equate file existence or a quote match with rating correctness.

References are assistant prepared and all provisional or contested. There are no settled correctness records; do not calculate an accuracy statistic. Publish reference agreement, if calculated, only as an exploratory comparison to assistant proposals with alternatives, with all denominators. Review selected examples using a fixed rule: repetition 1 for all three benchmarks and both access conditions, never replace a case for narrative fit. Record assistant interpretations and limits, not invented human agreement. Unreviewed semantic support remains unreviewed; no estimated error rate from a convenience sample.

Aggregate token counts from completion events, preserve unavailable counts as null, and distinguish pilot from main usage. Elapsed times are process times, not human effort. Report source extraction limits, paper/repository edition differences, the pilot delivery failure, three benchmark scope and one requested model. Claude is pending, not an empty or zero result group.
